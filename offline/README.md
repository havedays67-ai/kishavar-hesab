# اپ آفلاین کشاورزحساب (MVP)

این پوشه، هسته‌ی وب‌اپ آفلاین را دارد که داخل APK کپی می‌شود. هیچ درخواست شبکه‌ای ندارد.

## ساخت

```bash
npm run build:offline   # offline/app.ts → capacitor-web/app.js
```

CI همین کار را قبل از `npx cap add android` انجام می‌دهد.

## امکانات

- ثبت هزینه/درآمد با موتور قطعی `parseAmount` (تومان)
- دستیار محلی: تشخیص هزینه/درآمد، مبلغ، دسته و تاریخ؛ ساخت پیش‌نویس و ثبت فقط با تأیید
- پشتیبان: فقط راهنمایی، بدون نوشتن
- گزارش ماهانه، تفکیک دسته‌ها، خروجی JSON
- لاگ عملیات و واگرد (undo) برای هر ثبت/حذف
- ذخیره‌سازی: `localStorage` با کلید `kishavar.offline.v1`

## محدودیت‌های MVP

- هنوز SQLite نیست؛ برای نسخه نهایی به `@capacitor-community/sqlite` و اسکیمای `src/lib/engine/localdb.ts` منتقل می‌شود.
- مدل زبانی همراه APK نیست؛ NLU فعلی قاعده‌محور است.
- خروجی JSON در WebView اندروید ممکن است به اشتراک‌گذاری نیاز داشته باشد (نسخه بعد: Share plugin).

## تست

تست DOM با jsdom (خارج از ریپو) انجام شد: ثبت دستیار، تأیید، گزارش، حذف/واگرد، و جریان پرسیدن مبلغ.
