# اپ آفلاین کشاورزحساب (نسخه بازطراحی‌شده)

این پوشه هسته و رابط کاربری وب‌اپی است که داخل APK کپی می‌شود. هیچ درخواست شبکه‌ای ندارد
(`connect-src 'none'` در CSP) و همه داده‌ها روی همان دستگاه می‌مانند.

## ساخت

```bash
npm run build:offline   # offline/app.ts → capacitor-web/app.js (esbuild، باندل IIFE)
```

CI پیش از `npx cap add android` همین کار را انجام می‌دهد.

## معماری

```
offline/
  engine.ts     موتور قطعی: پول، تقویم شمسی، اعتبارسنجی سند دوطرفه،
                جمع فاکتور/مالیات، مانده، ترازنامه، استهلاک، جدول اقساط، Aging
  store.ts      ذخیره‌سازی محلی + عملیات (هزینه، درآمد، انتقال، فاکتور،
                دریافت/پرداخت، چک، وام/قسط، انبار، دارایی، بودجه، زمین) + Audit
  assistant.ts  دستیار قاعده‌محور: فقط تشخیص قصد و اسلات؛ بدون محاسبه مالی
  ui.ts         رابط کاربری (ناوبری، فرم‌ها، گزارش‌ها، پشتیبان)
  app.ts        نقطه ورود
```

قواعد ثابت:

1. تنها راه نوشتن، `postEntry` است که `validatePosting` را اجرا می‌کند (جمع بدهکار = بستانکار).
2. هیچ مانده/سود/مالیاتی ذخیره نمی‌شود؛ همه از ردیف‌های دفتر بازمحاسبه می‌شوند.
3. دستیار فقط پیش‌نویس می‌سازد؛ ثبت با تأیید کاربر و از مسیر موتور انجام می‌شود.
4. حالت «پشتیبان» در تنظیمات، ثبت سند را غیرفعال می‌کند (فقط خواندن).

## امکانات این نسخه

- داشبورد: نقدینگی، سود دوره، روند ۶ ماه، هشدار چک/قسط/انبار/بودجه، **کارت بدهکاران و بستانکاران**، آخرین اسناد
- دفتر روزنامه: جست‌وجو، ردیف‌های بدهکار/بستانکار، واگرد سند
- ثبت: هزینه، درآمد، انتقال، فاکتور فروش/خرید (تخفیف و مالیات)، دریافت/پرداخت با تخصیص فاکتور،
  چک دریافتی/پرداختی با وصول و برگشت، وام و اقساط، انبار، دارایی ثابت، بودجه، طرف‌حساب، زمین و عملیات مزرعه
- **دفتر معین طرف‌حساب (بدهکار/بستانکار):** گردش کامل حساب با مانده‌ی تجمعی هر ردیف، تفکیک
  جمع بدهکار/بستانکار، فاکتورهای باز، چک‌های در جریان، مبلغ معوق، ثبت «مانده اول دوره» با ماهیت
  بدهکار یا بستانکار، و کپی صورتحساب متنی برای اشتراک‌گذاری
- **گزارش بدهکاران و بستانکاران:** فهرست جداگانه‌ی طلب‌ها و بدهی‌ها با جمع، معوق و دکمه‌ی صورتحساب
- گزارش‌ها: سود و زیان، جریان نقد، سنّی مطالبات، ترازنامه، مالیات، طرف‌حساب‌ها، **بدهکار/بستانکار**،
  **تراز آزمایشی با دفتر معین هر حساب**، بودجه در برابر واقعی، ارزش موجودی،
  ارزش دفتری دارایی‌ها، سود زمین
- دستیار محلی با ۳۶ قصد و پاسخ‌های قطعی؛ شامل **توضیح کامل هر بخش** («بخش چک را کامل توضیح بده»)،
  فهرست بدهکاران/بستانکاران و **صورتحساب هر طرف‌حساب** («صورتحساب شرکت لبنیات دشت»)
- **راهنمای ۱۴ بخش داخل اپ:** هر صفحه دکمه‌ی «؟ راهنما» دارد و از «بیشتر › راهنمای کامل بخش‌ها» هم
  همه‌ی راهنماها (چیست، گام‌به‌گام، نکته، نمونه جمله) در دسترس است
- پشتیبان JSON (کپی/دانلود)، خروجی CSV دفتر، بازیابی، داده‌ی نمونه، پاک‌سازی، تم روشن/تیره، تقویم شمسی و تومان

## ذخیره‌سازی و مهاجرت

- کلید جدید: `kishavar.offline.v2`
- داده‌ی نسخه قبلی (`kishavar.offline.v1`، تراکنش‌های تک‌طرفه) در اولین اجرا به سندهای دوطرفه تبدیل می‌شود.
- `localStorage` تنها ذخیره‌گاه است؛ برای حجم بالاتر، انتقال به SQLite با همان قرارداد موتور در نسخه بعد انجام می‌شود.

## تست

```bash
npx vitest run tests/offline-engine.test.ts
```

۴۰ تست برای پول/تقویم/سند دوطرفه/فاکتور/مالیات/چک/وام/استهلاک/گزارش‌ها/دستیار، دفتر معین
طرف‌حساب، مانده اول دوره، تراز آزمایشی و راهنمای بخش‌ها.

## محدودیت‌ها

- مدل زبانی همراه APK نیست؛ دستیار قاعده‌محور و آفلاین است.
- اسکن رسید، اتصال بانک و چندارزی در این نسخه نیست (مستند در `docs/ROADMAP-DECISION.md`).
- دانلود فایل پشتیبان در برخی WebViewها محدود است؛ دکمه‌ی پشتیبان در صورت خطا، متن را در کلیپ‌بورد کپی می‌کند.
