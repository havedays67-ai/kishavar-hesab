# لایهٔ فهم سریع کشاورزیار — گزارش واقعی (نسخه ۱.۰.۰)

> همهٔ عددهای این سند خروجی اجرای واقعی `tools/build_pack/eval.ts` و
> `tools/build_pack/build-pack.ts` روی همین مخزن است. هیچ عددی دستی
> نوشته نشده. مدل زبانی روی دستگاه در این نسخه همراه APK **نیست**.

## ۱) معماری

```
ورودی فارسی
  → Normalizer (ارقام، ی/ک، نیم‌فاصله، واحد، عدد حرفی، ماسک مبلغ)
  → Rule Engine (قواعد قطعی کشاورزی، خروجی intent+slots+confidence)
  → Learned Cache (نگاشت محلی جمله→intent/slots، LRU، بدون مبلغ)
  → Answer Pack (ایندکس هش ۳۲بیتی روی جملهٔ ماسک‌شده، باینری)
  → Support Retriever (TF-IDF، فقط حالت پشتیبان)
  → Model Fallback (مدل کوچک؛ فعلاً وصل نیست → سؤال شفاف)
```

هر سطحی که پاسخ معتبر با اطمینان کافی داد، بقیه اجرا نمی‌شوند.
**هیچ مبلغ/موجودی/نتیجهٔ گزارشی در کش یا بسته ذخیره نمی‌شود**؛ کلید
جمله اعداد را ماسک می‌کند و مقدار فقط intent + برچسب متنی است.

## ۴) چه چیزی کار کرد

- نرمال‌سازی: ورودی‌های معادل (ارقام فارسی/عربی، ی/ک عربی، نیم‌فاصله،
  عدد حرفی، واحد) یک کلید یکسان می‌سازند و مبلغ در کلید حذف می‌شود.
- قواعد: روی جمله‌های رایج 100% دقت intent؛
  زیررشته‌های نادرست (مثل «سم» در «بنویسم») با تطبیق واژه‌ای حذف شد.
- بسته/کش: بدون هیچ عدد مالی؛ آزمون خودکار این را تضمین می‌کند.
- سرعت: میانگین 0.33ms و p95 0.52ms روی Node،
  بدون هیچ فراخوانی مدل.

## ۵) چه چیزی هدف را نگرفت (صادقانه)

- هدف **۹۸٪ intent** با 99.15% به‌دست نیامد
  (کمتر از هدف؛ عدد گرد نشده). بیشترین خطاها: جمله‌های محاوره‌ای با فعل
  مبهم («دادم» برای هزینه/چک/وام) و جمله‌های چندقصدی.
- تطابق **کامل** اسلات‌ها 56.25% است، چون برچسب
  طلایی فقط چند اسلات را لازم می‌داند و تشخیص دسته/محصول اضافه،
  «نادرست» شمرده می‌شود؛ recall اسلات 87.43% است.
- **مدل روی دستگاه نداریم**: هیچ وزنی در مخزن نیست، پس مقایسهٔ
  «فقط مدل» انجام نشد و عددی برای آن گزارش نمی‌شود. مسیر اتصال
  (`setModelRunner` + اعتبارسنج سخت) آماده است.
- زمان‌ها روی Node اندازه‌گیری شده، نه روی گوشی ۶GB؛ بنچمارک دستگاه
  باید جداگانه اجرا شود.

## ۶) گام بعدی پیشنهادی

1. جمع‌آوری جمله‌های واقعی (با رضایت کاربر، بدون مبلغ) و افزودن به
   پیکره، مخصوصاً خانوادهٔ «دادم» برای رفع ابهام فعل.
2. آموزش مدل کوچک QLoRA روی همین دیتاست و اتصال با `setModelRunner`
   + constrained JSON؛ سپس اندازه‌گیری واقعی دقت/RAM روی گوشی.
3. افزودن ایندکس n-gram به بسته برای تعمیم جزئی بدون مدل، و بنچمارک
   مجدد nرخ Hit.
